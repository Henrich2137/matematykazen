# 6. Wzory skróconego mnożenia

Strona **7** tablicy.

## [6.1] Kwadrat i sześcian sumy oraz różnicy — s. 7, środek

Dla dowolnych liczb rzeczywistych \(a\), \(b\):

\[(a + b)^2 = a^2 + 2ab + b^2 \qquad (a + b)^3 = a^3 + 3a^2 b + 3ab^2 + b^3\]

\[(a - b)^2 = a^2 - 2ab + b^2 \qquad (a - b)^3 = a^3 - 3a^2 b + 3ab^2 - b^3\]

## [6.2] Różnica \(n\)-tych potęg — s. 7, środek

Dla dowolnej liczby całkowitej dodatniej \(n\) oraz dowolnych liczb rzeczywistych \(a\), \(b\) mamy:

\[a^n - b^n = (a - b)(a^{n-1} + a^{n-2} b + \ldots + a^{n-k} b^{k-1} + \ldots + ab^{n-2} + b^{n-1})\]

## [6.3] Przypadki szczególne — s. 7, środek/dół

W szczególności:

\[a^2 - b^2 = (a - b)(a + b) \qquad a^2 - 1 = (a - 1)(a + 1)\]

\[a^3 - b^3 = (a - b)(a^2 + ab + b^2) \qquad a^3 - 1 = (a - 1)(a^2 + a + 1)\]

\[a^3 + b^3 = (a + b)(a^2 - ab + b^2) \qquad a^3 + 1 = (a + 1)(a^2 - a + 1)\]

\[a^n - 1 = (a - 1)(a^{n-1} + a^{n-2} + \ldots + a + 1)\]
