# 1. Wartość bezwzględna liczby

Strona **4** tablicy.

## [1.1] Definicja wartości bezwzględnej — s. 4, góra

Wartość bezwzględną liczby rzeczywistej \(x\) definiujemy wzorem:

\[|x| = \begin{cases} x & \text{dla } x \ge 0 \\ -x & \text{dla } x < 0 \end{cases}\]

Liczba \(|x|\) jest to odległość na osi liczbowej punktu o współrzędnej \(x\) od punktu o współrzędnej \(0\).

## [1.2] Własności podstawowe — s. 4, góra

Dla dowolnej liczby \(x\) mamy:

\[|x| \ge 0 \qquad |x| = 0 \text{ wtedy i tylko wtedy, gdy } x = 0 \qquad |-x| = |x|\]

## [1.3] Działania na wartościach bezwzględnych — s. 4, środek

Dla dowolnych liczb rzeczywistych \(x\), \(y\) mamy:

\[|x + y| \le |x| + |y| \qquad |x - y| \le |x| + |y| \qquad |x \cdot y| = |x| \cdot |y|\]

Ponadto, jeśli \(y \ne 0\), to:

\[\left| \frac{x}{y} \right| = \frac{|x|}{|y|}\]

## [1.4] Wartość bezwzględna w nierównościach — s. 4, dół

Dla dowolnych liczb rzeczywistych \(a\) oraz \(r \ge 0\) mamy:

\[|x - a| \le r \text{ wtedy i tylko wtedy, gdy } a - r \le x \le a + r\]

\[|x - a| \ge r \text{ wtedy i tylko wtedy, gdy } x \le a - r \text{ lub } x \ge a + r\]

> Uwaga: tablica podaje te równoważności **wyłącznie dla nierówności** (\(\le\), \(\ge\)).
> Odpowiednika dla równania \(|x - a| = r\) w tablicy nie ma — przy równaniach
> trzeba wyjść od definicji [1.1] i rozpatrzeć dwa przypadki.
