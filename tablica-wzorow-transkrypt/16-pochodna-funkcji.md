# 16. Pochodna funkcji

Strony **32–33** tablicy (sekcja zaczyna się na dole s. 32).

## [16.1] Pochodna sumy, różnicy, iloczynu i ilorazu funkcji. Pochodna funkcji złożonej — s. 32, dół

\[[c \cdot f(x)]' = c \cdot f'(x) \quad \text{dla } c \in \mathbb{R}\]

\[[f(x) + g(x)]' = f'(x) + g'(x)\]

\[[f(x) - g(x)]' = f'(x) - g'(x)\]

\[[f(x) \cdot g(x)]' = f'(x) \cdot g(x) + f(x) \cdot g'(x)\]

\[\left[ \frac{f(x)}{g(x)} \right]' = \frac{f'(x) \cdot g(x) - f(x) \cdot g'(x)}{[g(x)]^2} \quad \text{gdy } g(x) \ne 0\]

\[[g(f(x))]' = g'(f(x)) \cdot f'(x)\]

## [16.2] Pochodne wybranych funkcji — s. 33, góra/środek

Niech \(a\), \(b\), \(c\), \(r\) będą dowolnymi liczbami rzeczywistymi.

| funkcja | pochodna funkcji |
|---|---|
| \(f(x) = c\) | \(f'(x) = 0\) |
| \(f(x) = ax + b\) | \(f'(x) = a\) |
| \(f(x) = ax^2 + bx + c\) | \(f'(x) = 2ax + b\) |
| \(f(x) = x^r\) | \(f'(x) = r \cdot x^{r-1}\) |
| \(f(x) = \dfrac{a}{x}\) | \(f'(x) = -\dfrac{a}{x^2}\) |
| \(f(x) = \sqrt{x}\) | \(f'(x) = \dfrac{1}{2\sqrt{x}}\) |
| \(f(x) = \sin x\) | \(f'(x) = \cos x\) |
| \(f(x) = \cos x\) | \(f'(x) = -\sin x\) |
| \(f(x) = \operatorname{tg} x\) | \(f'(x) = \dfrac{1}{(\cos x)^2}\) |
| \(f(x) = e^x\) | \(f'(x) = e^x\) |

gdzie \(e\) jest liczbą Eulera; \(e \approx 2{,}72\).

## [16.3] Równanie stycznej — s. 33, środek/dół

Jeżeli funkcja \(f\) ma pochodną w punkcie \(x_0\), to równanie stycznej do wykresu funkcji \(f\) w punkcie \((x_0, f(x_0))\) dane jest wzorem:

\[y = a(x - x_0) + f(x_0)\]

gdzie:

\[a = f'(x_0)\]
